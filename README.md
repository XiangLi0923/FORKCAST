# FORKCAST
FORKCAST·食序  SLOGAN:终结决策疲劳，闭环BC两端。此次比赛我们把应用场景限定在校园午餐选择和食堂备餐。学生端输入预算、时间和口味，即可获得可解释的个性化餐次推荐。菜品售罄时，系统推荐可行替代，保留原有意向，由学生决定是否换餐。运营端仅汇总授权需求，结合库存、原料与产能提出备餐建议，经人工批准后在下一供餐窗口生效，并反馈给学生端推荐。本版本使用模拟校园数据，可在本地运行，提供 MCP 工具供受授权宿主接入。 C 端提供完整餐次推荐、条件调整、换荐及可选授权。B 端区分偏好、意向和用餐自报，从可见信号估算需求，结合计划、产能和原料提出备餐建议。食堂人员批准后，系统在下一供餐窗增加模拟供给，发布快照与审计。演示通过有无确认同场景对照验证双端联动。
