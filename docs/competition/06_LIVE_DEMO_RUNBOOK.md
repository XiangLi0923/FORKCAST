# 现场双端演示手册

## 开场前

用 submission/RUN_GUIDE.md 在 Edge 所在桌面的原生 Windows PowerShell 启动独立演示数据库。保留原验收数据库。打开学生端和运营端，确认健康检查可达。运营者登录后发放一次性演示凭据，学生在 120 秒内加入演示。进入录制前清空输入框并隐藏所有凭据、头像、路径和报名身份。

## 2 分 50 秒独立演示

| 用时 | 操作 | 必须看到 |
| --- | --- | --- |
| 0:00–0:22 | C 输入预算 20 元、时间 45 分钟、指名烤鸭饭，更新推荐 | 模拟时钟 11:40，烤鸭首选 |
| 0:22–0:47 | 开启分享，明确选烤鸭。切 B | P/I/A 为 4/6/3 |
| 0:47–1:15 | B 推进 11:41，标记烤鸭售罄。切 C | 鸡腿饭首选，保留烤鸭意向 |
| 1:15–1:52 | B 推进 11:42，生成建议，填 3 并点「确认备餐」 | 建议追加三份；确认后 W1 库存仍 0 |
| 1:52–2:29 | B 推进 12:00，展开历史状态与审计，切 C | 已生效、库存 3、确认与生效两条记录；C 回荐烤鸭 |
| 2:29–2:50 | 展示同场景对照结果 | 无批准路径库存 0，C 首选鸡腿 |

推进使用界面模拟时钟。用户的演示凭据及 MCP 回执按真实时间到期。备餐操作明确为网页 HTTP，切勿点「授权本地 Agent」来替代比赛主线。

## 降级和录制

- 页面短时未更新，等待一次刷新。若仍超时，切回 PPT 第 4–6 页与 evidence/ 目录中的历史实跑截图，说明当前改为展示历史截图和独立复验。不要反复访问端口。
- 若条目已售罄、批准或跨窗，确认是在全新独立比赛库后再开始一次新演示。切勿在旧验收库复位或重放原提案。
- 用 Windows 截图工具或已安装的录屏工具框选网页区域。凭据录入时暂停，导出 MP4 后完整回放并核对时长、隐私和数据标识。当前附件提供录制脚本与真实历史截图，未包含录屏成片。
- PPT 主讲和现场视频二选一计入三分钟预算。问答时才展开技术细节。
