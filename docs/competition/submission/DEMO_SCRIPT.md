## 人工录屏

1. Windows 11 打开「截图工具」的录屏模式，或使用已安装的录屏软件。框选应用网页，隐藏账号头像、浏览器收藏、通知、终端、个人路径及所有输入凭据的窗口。按需打开麦克风。
2. 先空跑检查切换，再在另一份新比赛库录正片。只在核实属于比赛演示的独立数据库后才可复位演示运行。
3. 保存 MP4 并回放，检查总长不超过三分钟、关键信息可读、无本人姓名学号或凭据。上传后从无登录窗口核查视频可访问性（若规则要求）。
4. 若原生 Edge 健康检查失败，保留报错和时间，停止反复尝试。赛方允许时可附历史界面证据与本次程序复验结果，标明来源。当前未录制比赛视频。
