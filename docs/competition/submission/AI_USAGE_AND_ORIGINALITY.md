# AI 使用及原创性说明

- ChatGPT 与 Codex 用于需求整理、数据与接口设计辅助、实现与测试、工程验收和文档草拟。现有项目记录未逐项标注精确模型版本。参赛人如使用过其他模型或工具，请据实补充。
- 作品围绕校园午餐选择成本，设计和实现学生推荐、供餐变化重规划、受授权需求聚合、运营备餐提案、人工批准、供餐窗口生效与审计。数据契约、规则、界面、本地 MCP 工具及测试随源码交付。
- 推荐和备餐决策由本地规则与模拟数据驱动。演示运行无需使用云端模型。MCP 提供外部宿主连接接口。学生分享和运营批准由实际操作者决定。
- 模拟夹具由项目构造。演示不使用真实学生记录或真实食堂交易数据。
- 第三方依赖包括 Python、SQLite、Pydantic、Starlette、Uvicorn、httpx2、jsonschema 和 MCP Python SDK。Node.js 用于前端自动化。固定版本见依赖文件，并遵循依赖各自的许可。未为作品新增或声明开源许可，若表单要求公开范围，由参赛人确认。
