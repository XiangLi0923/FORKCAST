# 已知问题与比赛影响

| 问题 | 当前处理 |
| --- | --- |
| GATE 1 BLOCKED | 缺可见 Edge 人工签发、同一新运行的首次 MCP Host 成功返回、HTTP 与数据库同快照读回以及四张截图。比赛脚本使用已完成复验的网页 HTTP 运营确认，保留正确标注。 |
| 部分运行会话与原生 Edge 回环不通 | 历史 8771、8773、8781 均有可见 Edge 超时记录。本次盘点无可见 Edge 窗口，命令会话未能访问 8773 或 8781。从解压源码独立启动的 Uvicorn 在同一验证进程能提供 HTTP 服务。演示时在 Edge 同桌面的原生 PowerShell 启动独立比赛服务，按指南执行一次健康检查。 |
| 终端直连 PyPI DNS 不稳定 | 优先复用已验证环境，或按 GATE 2 的方式用经校验的 wheelhouse 离线安装。 |
| 平台细则需登录核对 | ANS 公共赛事入口可确认，赛事专区读取超时。待确认格式、视频/仓库字段及提交回执。 |
| 所有示例都是模拟数据 | 原库、现场日志、私有运行身份与凭据留在现场。源码含可复用模拟夹具。 |
