# 作品名称与简介

**作品名称** FORKCAST（食序）V0.3  
**建议赛道** 生活与智能体，以报名表为准。

## 20 秒口播

食序帮学生根据预算、时间和当下供应决定午餐。菜品售罄会换荐，学生原有选择继续保留。运营者根据授权汇总决定备餐，新供给生效后又回到学生推荐里。

## 200 字以内提交版

食序把校园午餐选择和食堂备餐连成一个闭环。学生输入预算、时间和口味，即可获得可解释的个性化餐次推荐。菜品售罄时，系统推荐可行替代，保留原有意向，由学生决定是否换餐。运营端仅汇总授权需求，结合库存、原料与产能提出备餐建议，经人工批准后在下一供餐窗口生效，并反馈给学生端推荐。本版本使用模拟校园数据，可在本地运行，提供 MCP 工具供受授权宿主接入。

## 扩展简介

C 端提供完整餐次推荐、条件调整、换荐及可选授权。B 端区分偏好、意向和用餐自报，从可见信号估算需求，结合计划、产能和原料提出备餐建议。食堂人员批准后，系统在下一供餐窗增加模拟供给，发布快照与审计。演示通过有无确认同场景对照验证双端联动。MCP 接入已做协议实测，浏览器人工回执仍待验收。
