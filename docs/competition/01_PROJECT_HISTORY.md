# FORKCAST 项目历程

校园午餐受课间时间、步行、排队、预算和临时供给共同影响。前期讨论过评价、人格化推荐、预约支付等方向。比赛范围最终集中到校园午餐选择和真实可运行的供需反馈闭环。中国农大东校区是早期场景背景，现有运行采用自造模拟数据。

## 复盘

- 浏览、明确意向和用餐自报独立记账。将曝光或自动重规划算作需求会污染提案。
- 用同一运行的 W1 售罄、W2 生效、C 端重新推荐和未确认对照证明闭环。
- 分别看网页 HTTP、SDK 协议与可见 Edge 人工回执证据。前两类通过，最后一类仍缺完整首调证据。
- 真实校园试点需先验证数据授权、时效和质量，再测选择耗时、推荐接受与备餐采纳。当前没有真实运营成效统计。

资料来自早期 PRD V0.2、五份 M0 规范、仓库 Git、阶段验收报告与比赛源码独立复验。
